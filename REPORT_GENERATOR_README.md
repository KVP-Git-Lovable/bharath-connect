# SBEE Cables Weekly Report Generator

## 📊 Overview
Generate comprehensive weekly executive reports in PDF format with all leads, activities, and user performance data. The report automatically excludes specified users (Suyog, Prajwal, Shravan, Ajay) and includes the SBEE logo with professional formatting.

## 📋 Report Contents
- **SBEE Logo & Branding** - Professional header with company name
- **Key Metrics** - Total leads, activities, users, and pipeline value
- **Leads Table** - All leads with owner, company, status, value, and creation date
- **Activities Breakdown** - Activities by type with counts
- **User Performance** - Each user's leads owned and activities completed
- **Generated Timestamp** - Automatic date/time stamp

## 🚀 Quick Start

### Option 1: Automated Setup (Recommended)
```bash
./run_report.sh
```

This script will:
1. Check for Python 3
2. Install required dependencies (python-supabase, reportlab, pillow)
3. Load environment variables from .env.local
4. Generate the PDF report
5. Display the output filename

### Option 2: Manual Setup
```bash
# Install dependencies
pip3 install python-supabase reportlab pillow

# Run the generator
python3 generate_weekly_report.py
```

### Option 3: Using Environment Variables
If .env.local is not available, set environment variables:
```bash
export VITE_SUPABASE_URL="your_supabase_url"
export VITE_SUPABASE_ANON_KEY="your_supabase_key"

python3 generate_weekly_report.py
```

## 📁 Output Files
Generated PDF files are named: `SBEE_Weekly_Report_YYYY-MM-DD_HH-MM-SS.pdf`

Example: `SBEE_Weekly_Report_2026-08-13_14-30-45.pdf`

## 🚨 Troubleshooting

### "Command not found: python3"
Install Python 3: https://www.python.org/downloads/

### "ModuleNotFoundError: No module named 'supabase'"
Run: `pip3 install python-supabase reportlab pillow`

### "SUPABASE_URL not found"
Make sure `.env.local` exists or set environment variables:
```bash
export VITE_SUPABASE_URL="..."
export VITE_SUPABASE_ANON_KEY="..."
```

### Report is missing data
- Check Supabase connection
- Verify user credentials
- Ensure database has active records
